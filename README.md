## 🚀 Overview

This project is an art-directed, competition-grade website redesign for **Karka AI & Tech Academy**, situated in **Nagercoil, Kanyakumari District, Tamil Nadu**.

The redesign establishes a high-performance, dark cyber-editorial technology aesthetic, communicating:
1. **The Exclusive AI Learning Center in Nagercoil:** Physical campus with daily mentorship.
2. **Pay After Placement (PAP) Model:** Learn with ₹0 upfront tuition; pay only after securing a tech career.
3. **The 4-Pillar Job-Readiness Framework:** Business Language (LSRW), Scalable App Engineering, Core AI Skills & Tools, and ATS Mock Interviews.
4. **Authentic Hiring Partners:** Amazon, TCS, HCL, Matrimony.com, Novac, Capecom, Flow, and Sodisys.
5. **Karka Ecosystem:** Highlighting **Spike AI** (Karka's AI learning platform) and **Karka Infini AI** (the ₹1,00,000 inter-college student championship featuring SiteSprint).

---

## 🛠️ Technology Stack

* **Structure:** Semantic HTML5 with Schema.org `EducationalOrganization` JSON-LD and OpenGraph metadata.
* **Styling:** Pure Vanilla CSS3 with custom design tokens, responsive CSS Grid, Flexbox, glassmorphic card overlays, and subtle keyframe animations.
* **Interactions:** Vanilla JavaScript (ES6+) for accessible mobile navigation, dynamic category filtering, scroll-spy active link tracking, and accessible FAQ accordion.
* **Animation:** Restrained, smooth GSAP 3.15.0 entrance reveals (with graceful fallback for `prefers-reduced-motion`).
* **Zero Bloat:** Zero heavyweight frameworks (No React, Vue, or Angular), ensuring instant load speed and peak Lighthouse scores.

## 💻 How to Run the Project Locally

Because this project is built entirely on native web standards, it requires no build step or package installations.

### Option 1: Python HTTP Server (Recommended)
```powershell
python -m http.server 3000
```
Then navigate to: `http://localhost:3000`

### Option 2: Node.js / NPX
```powershell
npx -y serve .
```

### Option 3: Direct Browser Launch
Open `index.html` directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.
